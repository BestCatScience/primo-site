Primo サポート

Primo は、Apple Pencil で描く iPad 向けのペイントアプリです。

お問い合わせ

不具合やご要望は、bestcatscience@gmail.com までお送りください。お使いの iPad の機種、iPadOS のバージョン、起きたことをお書きいただけると助かります。

よくある質問

AI 編集を使うには何が必要ですか。
OpenAI、Google、xAI のいずれかの API キーが必要です。キーは各社のサイトで作成し、本アプリの設定の「AI の API キー」に保存します。利用料金は各社から直接請求されます。

作品はどこに保存されますか。
お使いの iPad の中です。運営者のサーバーには送信されません。AI 編集を使うときは、同意したサービスへ画像と指示文が送信されます。詳しくはプライバシーポリシーをご覧ください。

作品を別のアプリで開けますか。
ファイルメニューから、PNG、JPEG、レイヤーを保った PSD で書き出せます。

AI サービスへの送信の同意を取り消すには。
設定の「AI の API キー」で、そのサービスのキーを削除してください。

FAQ

What do I need to use AI editing?
An API key from OpenAI, Google or xAI. Create it on the provider's site and save it under AI API Key in the app's settings. The provider bills you directly.

Where is my artwork saved?
On your iPad. It is not sent to servers run by us. When you use AI editing, the image and your instructions are sent to the service you agreed to. See the Privacy Policy.

Can I open my artwork in other apps?
Yes. Export PNG, JPEG, or PSD with layers from the File menu.

How do I withdraw consent to send to an AI service?
Delete that service's key under AI API Key in settings.
