Primo プライバシーポリシー

施行日: 2026年11月6日

Primo(以下「本アプリ」)は、BestCatScience(以下「運営者」)が提供する iPad 向けのペイントアプリです。本ポリシーは、本アプリが扱う情報とその取り扱いを説明します。

運営者が取得する情報

運営者は、利用者の作品、API キー、指示文などの情報を取得しません。本アプリには利用状況の解析や広告のための仕組みがなく、他のアプリやウェブサイトをまたいだ追跡もありません。

本アプリは起動時などに、更新の有無を確かめるため、運営者が GitHub Pages で公開しているファイルを読み込みます。この通信に作品や個人を識別する情報は含めませんが、GitHub には通常のウェブアクセスと同様に IP アドレスなどが記録されることがあります。

端末に保存する情報

次の情報は、利用者の端末に保存します。

  • 作品: 作品のデータ、レイヤー、取り消しの履歴、タイムラプスなど。
  • 設定: ブラシ、表示、各 AI サービスへの送信の同意状況など。
  • API キー: 利用者が入力した AI サービスの API キー。端末の Keychain に保存し、作品の書き出しには含めません。

端末のバックアップや、利用者が選んだ書き出し先に作品が含まれる場合、その取り扱いは Apple や各サービスの規定に従います。

本アプリは、利用者が選んだ写真やファイルと、利用者が貼り付け操作をしたときのクリップボードの内容を、作品に取り込むために読み込みます。

AI 編集で第三者に送信する情報

AI 編集は任意の機能で、利用者自身の API キーが必要です。使わない限り、次の送信は行われません。

利用者が AI サービスを選び、そのサービスへの送信に同意したうえで「生成」を押すと、本アプリはその都度、次の情報を選択中のサービスへ直接送信します。

  • レイヤーまたはキャンバスの画像
  • 選択範囲がある場合はその情報(マスク画像、または選択範囲を赤で囲んだ画像)
  • 入力した指示文
  • サービスの認証に使う API キー

送信した情報は、各社の規約とプライバシーポリシーに従って扱われます。保存期間や、サービスの改善や学習への利用の有無は、会社や契約の種類によって異なります。たとえば Google は、Gemini API の無料枠に送信された内容を製品の改善に利用し、人が確認する場合があると説明しています。利用前に各社の説明をご確認ください。

他人の個人情報や機密情報を含む画像や指示文は、送信しないでください。

API の利用料金は、各サービスから利用者に請求されます。

同意の取り消しと情報の削除

  • 送信の同意: そのサービスの API キーを本アプリから削除すると、取り消されます。
  • API キー: 本アプリの「AI の API キー」の画面から削除できます。
  • 作品: 本アプリから削除できます。本アプリを削除すると、端末内のデータも削除されます。
  • 送信済みの情報: 運営者は保有していません。削除については、送信先の各社にお問い合わせください。

Apple が提供する情報

利用者が Apple との共有に同意している場合、運営者は Apple を通じて、個人を特定しない形のクラッシュ情報などを確認することがあります。TestFlight で試用している場合は、Apple の TestFlight の規定に基づく情報も確認することがあります。

お子様の利用

本アプリは、13 歳未満のお子様を対象としていません。AI 編集を使う場合は、各サービスの年齢要件に従ってください。

本ポリシーの変更

本ポリシーを変更する場合は、このページで内容と施行日を更新します。

Primo Privacy Policy

Effective date: November 6, 2026

Primo ("the app") is a painting app for iPad provided by BestCatScience ("we"). This policy explains the information the app handles and how it is treated.

Information we collect

We do not collect your artwork, API keys, instructions or similar information. The app has no analytics or advertising and does not track you across other apps or websites.

At launch and at similar times, the app reads a file we publish on GitHub Pages to check for updates. This request carries no artwork or information that identifies you, but GitHub may log your IP address and similar details as with any web request.

Information stored on your device

The following stays on your device:

  • Artwork: your documents, layers, undo history, timelapse and related data.
  • Settings: brushes, display options, and which AI services you have agreed to send to.
  • API keys: any AI service API key you enter. Keys are stored in the device Keychain and are not included in exported artwork.

If your artwork is included in a device backup or a location you export to, it is handled under the terms of Apple or that service.

The app reads the photos and files you choose, and the clipboard when you paste, in order to bring them into your artwork.

Information sent to third parties for AI editing

AI editing is optional and requires your own API key. None of the sending below happens unless you use it.

When you have chosen an AI service, agreed to send to it, and tapped Generate, the app sends the following directly to that service each time:

  • The layer or canvas image
  • Any selection (as a mask image, or as an image with the selection circled in red)
  • The instructions you entered
  • Your API key, to authenticate with the service

What you send is handled under each provider's terms and privacy policy. Retention, and whether it is used to improve or train services, depend on the provider and your plan. For example, Google says content sent to the unpaid Gemini API quota is used to improve its products and may be read by human reviewers. Please read each provider's terms before use.

Do not send images or instructions that contain other people's personal information or confidential information.

Each provider bills you directly for API use.

Withdrawing consent and deleting information

  • Consent to send: deleting that service's API key from the app withdraws it.
  • API keys: you can delete them on the app's AI API Key screen.
  • Artwork: you can delete it in the app. Deleting the app also deletes its data on the device.
  • Information already sent: we do not hold it. Please contact the provider you sent it to about deleting it.

Information provided by Apple

If you have agreed to share with Apple, we may see crash reports and similar information through Apple in a form that does not identify you. If you are testing through TestFlight, we may also see information under Apple's TestFlight terms.

Children

The app is not directed to children under 13. If you use AI editing, follow each service's age requirements.

Changes to this policy

If we change this policy, we will update its content and effective date on this page.
